# General Measure Options
---
Options available for use with all measures.
## Options
`Measure`
:   Type of the measure (e.g. `CPU`, `FreeDiskSpace` or `Plugin`). This option is required, and cannot not be changed dynamically.
`UpdateDivider` Default: `1`
:   Frequency at which the measure value is updated. The [`Update`](https://docs.rainmeter.net/manual/skins/rainmeter-section/#Update) option in the [Rainmeter] section of the skin is multiplied by the specified value to determine how often the measure is updated.
    **Example:** If `Update=1000` (in the [Rainmeter] section) and `UpdateDivider=30`, the measure is updated every 30 seconds.
    If `UpdateDivider=-1` or any negative number, then the measure is only updated once when the skin is loaded or refreshed.
`OnUpdateAction`
:   [Action](https://docs.rainmeter.net/manual/skins/option-types/#Action) to execute each time the measure is updated.
    **Note:** This may be based on the values in [Update](https://docs.rainmeter.net/manual/skins/rainmeter-section/#Update) in the [Rainmeter] section and any [UpdateDivider](https://docs.rainmeter.net/manual/measures/general-options/#UpdateDivider) on the measure, or if the measure is updated with a [Measure Bang](https://docs.rainmeter.net/manual/bangs/#Measure) or other relevant bang.
`OnChangeAction`
:   [Action](https://docs.rainmeter.net/manual/skins/option-types/#Action) to execute when the number or string value of the measure changes. The initial change from "nothing" to a value when the skin is loaded or refreshed is ignored.
    **Note:** With plugins that perform work in the background (e.g. [WebParser](https://docs.rainmeter.net/manual/measures/webparser/) and [FileView](https://docs.rainmeter.net/manual/plugins/fileview/)), the action will be executed on the initial change caused by the completion of the action when loading or refreshing the skin.
`InvertMeasure` Default: `0`
:   If set to `1`, the measure value is inverted.
    **Example:** With the [FreeDiskSpace](https://docs.rainmeter.net/manual/measures/freediskspace/) measure, this option can be used to measure the used disk space instead of the free disk space.
`MinValue` Default: `0.0`
:   The minimum value of a measure. This is used to set a range of values for use in meters that require a [percentual value](https://docs.rainmeter.net/manual/measures/#Percentage). The actual value of the measure will remain unchanged.
`MaxValue` Default: `1.0`
:   The maximum value of a measure. This is used to set a range of values for use in meters that require a [percentual value](https://docs.rainmeter.net/manual/measures/#Percentage). The actual value of the measure will remain unchanged.
`AverageSize` Default: `1`
:   If set, the measure value will be an average of the specified number of past actual values. This can be useful to create a smoother transition on some graphical meters using the measure value.
`DynamicVariables` Default: `0`
:   If set to `1`, the measure is dynamic.
    **See also:** [Dynamic Variables](https://docs.rainmeter.net/manual/variables/#DynamicVariables)
`Disabled` Default: `0`
:   If set to `1`, the measure value is never updated. A disabled measure always returns 0 as its value in numerical contexts (e.g. when used in a Calc formula or with IfActions), but may still return a previously obtained string value (e.g. when used in String meters).
    This value can be dynamically changed as needed with either the [!SetOption](https://docs.rainmeter.net/manual/bangs/#SetOption) bang or the [!EnableMeasure / !DisableMeasure / !ToggleMeasure](https://docs.rainmeter.net/manual/bangs/#EnableDisableToggleMeasure) bangs.
`Paused` Default: `0`
:   If set to `1`, the measure value is never updated. A paused measure will return its most recent number and/or string value.
    This value can be dynamically changed as needed with either the [!SetOption](https://docs.rainmeter.net/manual/bangs/#SetOption) bang or the [!UnpauseMeasure / !PauseMeasure / TogglePauseMeasure](https://docs.rainmeter.net/manual/bangs/#PauseMeasure) bangs.
`Group`
:   Defines a group or series of groups that the measure belongs to. For more information please see the [Groups](https://docs.rainmeter.net/manual/groups/) page.
